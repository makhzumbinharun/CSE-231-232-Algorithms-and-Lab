Problem Statement:

Implement a Sorting Algorithm that builds a binary tree from the input array and repeatedly extracts the maximum element, moving it to the end of the array. This process continues until the entire array is sorted in ascending order.

Input Format:

The first line contains an integer N, representing the number of elements in the array.
The second line contains N space-separated integers, representing the elements of the array.

Output Format:

Print the sorted array in ascending order.

Input Example:
```text
5
10 2 5 1 9
```
Output Example:
```text
1 2 5 9 10
```
