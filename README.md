## 📌 About This Repository

This repository contains my academic work for **CSE 231: Algorithm** and **CSE 232: Algorithm Lab** at Bangladesh University of Business and Technology (BUBT).

It includes theory materials, laboratory programs, lab reports, assignments, and practice problems related to algorithm design, analysis, and implementation.

The repository is actively maintained throughout the course, so additional files and folders may be added as the semester progresses.

## 📚 Course Topics

The **CSE 231: Algorithm** course covers fundamental algorithmic concepts, analysis techniques, and major algorithm design paradigms.

### Sorting & Analysis

* Insertion Sort
* Selection Sort
* Merge Sort
* Heap Sort
* Quick Sort
* Sorting in Linear Time
* Radix Sort
* Growth of Functions
* Asymptotic Notation
* Algorithm Analysis

### Divide and Conquer

* Divide and Conquer
* Merge Sort
* Strassen's Algorithm
* Maximum Subarray Problem

### Greedy Algorithms

* Greedy Algorithms
* Activity Selection
* Knapsack
* Analysis of Greedy Algorithms

### Dynamic Programming

* Dynamic Programming
* 0/1 Knapsack
* Longest Common Subsequence (LCS)
* Rod Cutting
* Analysis of Dynamic Programming Algorithms

### Graph Algorithms

* Breadth-First Search (BFS)
* Depth-First Search (DFS)
* Minimum Spanning Trees
* Kruskal's Algorithm
* Prim's Algorithm
* Dijkstra's Algorithm
* Bellman-Ford Algorithm
* Floyd-Warshall Algorithm
* Maximum Flow
* Ford-Fulkerson Algorithm

### Other Topics

* Sieve of Eratosthenes
* Recurrence Relations
* Substitution Method
* Recurrence Tree Method
* Master Method
